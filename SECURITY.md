# Security Policy

Do not put API keys, tokens, passwords, private documents, raw images, or model traces in a public Issue or Pull Request.

For a suspected vulnerability, use GitHub's private vulnerability reporting or security advisory flow when available. If that flow is unavailable, contact the repository owner privately through GitHub and include only a minimal reproduction.

Local configuration belongs in ignored `.env` files or a deployment secret store. Rotate any credential that appears in a commit, log, screenshot, or chat transcript.
