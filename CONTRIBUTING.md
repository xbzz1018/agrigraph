# Contributing

Keep contributions within the public, synthetic-data scope of this repository. Do not add customer material, raw images, private prompts, credentials, or external provider keys.

Before opening a Pull Request, run the backend Ruff/tests and the frontend type-check/build commands described in the README. Explain any skipped external acceptance clearly.

Use a feature branch and Pull Request. Keep changes focused, update relevant documentation, and describe data or security-boundary changes explicitly.
